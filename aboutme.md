Hi, I'm **Pham Hong Vinh** — an AI engineer based in Ho Chi Minh City, Vietnam.

I work on generative AI and on making it run well on limited hardware: diffusion models, 4-bit quantization, distillation, and the tooling around them. Most of what I do is open source.

### Selected projects

- [diffuser_layerdiffuse](https://github.com/rootonchair/diffuser_layerdiffuse) — create transparent images with Diffusers
- [diffuse-compressor](https://github.com/rootonchair/diffuse-compressor) — model-agnostic SVDQuant toolkit for diffusion transformers
- [nunchaku-lite](https://github.com/rootonchair/nunchaku-lite) — small, efficient runtime package for quantized diffusion models
- [consistency_models_distill](https://github.com/rootonchair/consistency_models_distill) — unofficial training scripts for consistency distillation models
- [dmlx](https://github.com/rootonchair/dmlx) — chat to create and edit images on your Mac, built on MLX
- [derot](https://github.com/rootonchair/derot) — one console for every Claude Code and Codex session, across projects and machines

### Hugging Face

I release models and model variants on [Hugging Face](https://huggingface.co/rootonchair) — currently tagged as **"GPU poor for Computer Vision, Generative AI, Multimodal"**. The focus is the same as on GitHub: making models run well on limited hardware.

- [diffuser_layerdiffuse](https://huggingface.co/rootonchair/diffuser_layerdiffuse) — transparent images with Diffusers
- [ERNIE-Image-Turbo-nunchaku-lite](https://huggingface.co/rootonchair/ERNIE-Image-Turbo-nunchaku-lite) and [MiniMax-H3-nunchaku-lite](https://huggingface.co/rootonchair/MiniMax-H3-nunchaku-lite-int4) — SVDQuant (int4/fp4) quantized diffusion models via nunchaku-lite
- [Lens-Turbo-GGUF](https://huggingface.co/rootonchair/Lens-Turbo-GGUF) — GGUF-quantized Lens-Turbo
- [LTX-2-19b-distilled](https://huggingface.co/rootonchair/LTX-2-19b-distilled) — distilled LTX-2 19B image-to-video model
- [InternVL2_5-4B-AWQ](https://huggingface.co/rootonchair/InternVL2_5-4B-AWQ) — AWQ-quantized InternVL2.5-4B
- [Vintern-3B-beta-GGUF](https://huggingface.co/rootonchair/Vintern-3B-beta-GGUF) — GGUF-quantized Vintern-3B
- [2x2_sticker_sheet](https://huggingface.co/rootonchair/2x2_sticker_sheet) — FLUX LoRA for 2x2 sticker sheets
